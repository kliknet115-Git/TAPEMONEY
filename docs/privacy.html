Kebijakan Privasi TAPEMONEY

Terakhir diperbarui: 24 November 2026

1. Prinsip Utama Privasi

TAPEMONEY adalah aplikasi iOS native yang mengutamakan privasi pengguna secara mutlak (Local-First & Offline-Only). Aplikasi ini dibuat semata-mata untuk membaca saldo kartu uang elektronik Anda melalui sensor NFC iPhone.

2. Data yang Dikumpulkan

Tidak ada data pribadi atau perbankan yang dikirim ke server luar.

  • Tanpa Akun: Anda tidak perlu mendaftar, memasukkan email, nomor telepon, PIN, atau kata sandi.
  • Tanpa Server Cloud: Seluruh riwayat scan, saldo, dan catatan transaksi disimpan hanya di memori internal perangkat iPhone Anda menggunakan SwiftData yang dilindungi oleh enkripsi iOS Data Protection.
  • Tanpa Telemetri Pihak Ketiga: Tidak ada pelacak analitik, iklan, atau SDK pelacak perilaku pengguna.

3. Operasi Read-Only

Aplikasi ini hanya membaca data chip kartu yang diizinkan untuk dibaca. TAPEMONEY tidak memiliki kemampuan untuk memodifikasi saldo, memotong dana, atau menulis instruksi finansial ke kartu fisik Anda.

4. Hak dan Kendali Pengguna

Anda memiliki kendali penuh atas data Anda:

  • Anda dapat menghapus riwayat per kartu atau menghapus seluruh database aplikasi kapan saja melalui menu Pengaturan.
  • Data dapat diekspor ke file CSV melalui iOS ShareSheet hanya bila Anda secara eksplisit menekan tombol ekspor.
